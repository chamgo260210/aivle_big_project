# 그 판을 어떻게 만들었나 — 재설계의 출발점

`market-report.html` 은 **이 재설계의 기준선이자 목표선**이다. 같은 재료로 그것이 나왔다는 것이
증명돼 있으므로, 자동 파이프라인은 **그보다 나아야** 한다.

이 문서는 그 판을 **재현 가능하게** 복원한다. 원장(`runs-generated/0c54ffb5-…`)과
`HANDOFF.md` §4·§8 에서 실측으로 맞춘 것이고, 추측은 없다.

---

## 1. 재료 — 무엇을 넣었나

**새로 검색하지 않았다.** 이미 있던 조사 한 판의 부산물만 썼다.

```
검색 704회  →  문서 후보 178건  →  본문 확보 · md5 중복 제거  →  112건 · 2,829,962자
```

- 원장: `runs-generated/0c54ffb5-b7bf-46b0-adc2-be284fed6acb`
- 컨셉: `data/concept_hmr-product.json` (프리미엄 냉동 간편식 · 1팩 8,900원 · 수도권 25~44세 1인 가구)
- ⚠ 이 112건은 **그 조사가 쓰지 않고 버린 것**이다. 파이프라인은 이 중 26건만, 그것도 앞 2만 자만 읽었다

## 2. 질문 — 어떻게 물었나 (**나빴다**)

수집 질문은 슬롯 17개였고, 그중 **웹 검색을 타는 것은 12개**(나머지 5개는 KOSIS·DART).
웹 슬롯은 **예외 없이 질의 6회 고정** → 질의 704개(`queries.txt`).

| 무엇을 물었나 | 슬롯 |
|---|---|
| 거래액 | 4 |
| 시장 점유율 | 2 |
| 회사 매출 | 1 |
| **가입 매장 수 · 누적 가입자 수 · 고객 획득 비용** | **4** ← 제조업에 물을 수 없는 것 |
| 문제 경험률 | 3 |
| 판매가 · 이용 요금 | 3 |

**채널 0 · 규제 0 · 원가 0.**

> **핵심** — 이 판의 재료는 **나쁜 질문이 물어온 것**이다. 그런데도 좋은 보고서가 나왔다.
> 「오뚜기 가입 매장 수」라는 헛질문이 물어온 43만 자 사업보고서 안에 **개당단가 6,513원**과
> **매출처별 채널 비중**이 있었다. **질문이 틀려도 문서는 옳을 수 있다.**

## 3. 코퍼스 재구성 — 어떤 모양으로 만들었나

```
a3_bodies.json (trace_id → 본문)
  → md5 로 중복 제거                        112건
  → run.jsonl 의 a3_candidate 에서 url·title 조인
  → 문서당 60,000자 상한                    2,829,962자 → 1,395,167자
  → 380,000자씩 덩어리로 분할                4개 파일 (corpus-01~04)
```

**한 파일에 문서 약 30건**이 함께 들어간다(문서 평균 12,457자).

⚠ **문서당 60,000자 상한은 지금 파이프라인과 똑같다.** 읽은 양은 차이가 아니다.
(상한에 걸린 문서는 6건, 잘린 글자 1,434,795 — 이것도 양쪽이 같다)

## 4. 읽기 — 어떻게 읽었나 (**여기가 다르다**)

**일반 에이전트에게 corpus 4개 파일 + 컨셉을 주고 「시장조사 보고서를 써라」고 시켰다.**

- **사실을 뽑으라고 하지 않았다.** 보고서를 쓰라고 했다
- 한 번에 **문서 30건씩** 봤다 — 문서를 넘나들며 합칠 수 있었다
- **뽑는 개수 상한이 없었다**
- **인용 대조·등급 판정을 거치지 않았다** (보고서 머리말에 그렇게 적혀 있다)

## 5. 무엇이 나왔나

9절 · 약 75개 사실. 그중 파이프라인이 못 냈던 것:

- 간편식 국내 판매액 **6조 8천억** (화면은 38조 × 가정 0.3 = 11.41조를 냈다)
- 냉동간편식 소매 **1조 1,666억** · 만두 외 **+46.5%**
- 오뚜기 냉동식품 **개당 평균단가 6,513원** → 8,900원은 **1.37배**
- 아워홈 온더고 — 점유율 **20%**, 누적 **2,000만 개**, 우리와 **같은 채널·같은 소구점**
- 오뚜기 매출처별 채널 비중 5행 · 간편식 온라인 구매 전체 46.6% vs **1인 가구 51.8%**
- 식료품제조업 영업이익률 **4% 미만** · 오뚜기냉동식품 순이익률 **2.6%**
- **2026년 즉석섭취·편의식품류 영양표시 의무화**

**그리고 값의 절반은 「뽑은 것」이 아니라 「쓴 것」이다:**

> 「8,900원은 같은 카테고리 평균단가(6,513원)의 **1.37배**」 ← 두 문서를 합쳐야 나온다
> 「**식사준비는 싫은데 식사는 좋다** — 이 간극이 이 카테고리의 수요입니다」 ← 한 조사의 두 표를 합쳤다
> 「**편의점 대체로 팔면 비싸고, 배달 대체로 팔면 설 자리가 있다**」 ← 여섯 값을 놓고 내린 판단

## 6. 지금 파이프라인과 무엇이 다른가

| | **그 판 (원본)** | **지금 (`read_sections.py`)** |
|---|---|---|
| 재료 | 112건 · 1,395,167자 | **같음** |
| 문서당 상한 | 60,000자 | **같음** |
| **한 번에 보는 문서** | **약 30건** (38만 자 덩어리) | **1건** |
| **지시** | **「보고서를 써라」** | 「이 문서가 9절 중 뭘 채우나」 |
| **뽑는 개수 상한** | **없음** | **문서당 20개** |
| **산출** | **문단 · 표 · 해석** | 사실 튜플 (값·단위·연도·subject·인용) |
| 문서 간 결합 | **가능** | **구조적으로 불가능** |
| 검증 | **없음** | 5겹 (인용 대조 · 절 코드 · 값-인용 일치 · 게재 5분류 · 출처 유형) |
| 결과 | **9절 중 7절 · 약 75개 사실** | **9절 중 4절 · 69개 사실** |

### 그래서 격차의 원인은 **둘**이다 (읽은 양도, 개수 상한도 아니다)

1. **문서를 하나씩 따로 본다** — 「8,900원은 6,513원의 1.37배」 같은 문장이 원리적으로 안 나온다.
   그리고 아무 문서도 「나는 채널이야」라고 말하지 않으므로 **채널 절이 0**이 된다
2. **쓰기 단계가 없다** — 지금은 표만 낸다. 원본 값어치의 절반이 해석이었다

> **⚠ 정정 (2026-08-14 · 이 문서 초판의 오류)**
> 초판은 원인으로 **「문서당 20개 상한」**과 **「문서의 14%만 읽는다」**를 들었다. **둘 다 틀렸다.**
> - **상한 20에 닿은 문서는 0건이다.** 최대 19 · 최빈 10 (`sections.json` 집계).
>   「43만 자에서 17개 뽑고 닫았다」는 예시부터 20이 아니다
> - **왕관 사실은 6만 자 상한에 안 잘렸다.** `6,513` · `1조1,666억` · `46.5%` · `46.6/51.8%` ·
>   `영양표시` 가 **전부 앞 6만 자 안**에 실재한다(`a3_bodies.json` 직접 검색)
> - **그리고 원본도 같은 60,000자 상한이었다.**
>
> 즉 **1패스는 그 글자를 읽고도 안 뽑았다.** 원인은 읽은 양이 아니라 **문서를 하나씩 본 것**이다.
> 정정 이력 전체는 `DECISIONS.md` 4부.

### 다만 지금이 나은 것도 있다 — 버리면 안 된다

원본은 **검증을 안 거쳤다**(스스로 명시). 지금은 5겹을 거치고, 그 과정에서 이런 것들을 잡았다:

- 인용 73건이 **그 값의 근거가 아니었다** (「8,980억원」인데 인용은 「셰프를 앰버서더로 발탁하여」)
- 게임회사 증권신고서 · 병원 회사소개서 · 자립준비청년 보고서에서 온 사실 163건
- 배달앱-입점업체 내부 경제 54건

**원본을 그대로 베끼면 이것들이 같이 들어온다.** 베낄 것은 **읽는 모양**이지 검증 부재가 아니다.

## 7. 그래서 다음 판의 모양

**폐기됐다.** 이유는 `archive/PASS2_DESIGN.md` 와 `DECISIONS.md` 3부)

```

         덩어리마다 "쓸 수치·사실을 개수 제한 없이 전부 뽑아라"
         ⚠ 절을 배정하지 않는다. 문단을 쓰지 않는다

[게이트] 5분류 + 중복 제거. LLM 0회 · 0원

[집필층] 절마다 1회. 살아남은 사실 + 컨셉값을 받아
         여기서 처음으로 절을 배정하고 문단·표·해석을 쓴다
```

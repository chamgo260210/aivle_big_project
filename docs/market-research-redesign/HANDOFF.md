# 시장조사 모듈 재설계 — 인수인계

**2026-08-14 작성.** 다음 세션은 이 문서부터 읽는다.

---

## 0. 다음 세션에서 할 일 — 순서 그대로

1. **`service-critic` 에 「시장조사 모듈을 처음부터 재설계하라」고 시킨다.**
   재료로 이 폴더 전부 + 아래 §2 진단 + §4 실증을 넘긴다.
   **구현이 아니라 서비스 단 파이프라인**을 설계하게 한다 (사용자가 무엇을 받는가 → 그러려면 무엇을 거쳐야 하는가).
2. **그 설계를 받아 상세 계획으로 살을 붙인다.** (판 나누기 · 파일 · 검증 · 유료 실행 지점)
3. **다시 `service-critic` 에 검사 맡긴다.**

⚠ 1번은 **새로 부르는 게 아니라 이어서** 부른다. 이전 세션의 판정 맥락은 사라졌으므로,
이 문서를 통째로 재료로 준다.

## 1. 이 재설계를 하게 된 이유 (한 문단)

사업 검증 화면이 사용자에게 「시장조사를 대신 해 줬다」고 말할 수 없는 상태였다.
근거 17건 중 12건이 우리 사업과 무관했고(배달비·편의점 도시락·남의 회사 전사 매출),
시장 크기는 **지어낸 점유율 0.3**을 곱해 만든 11.41조였으며, 엔진 자신은 최종 보고서에
**「추정 불가」**라고 적었는데 화면에는 값이 떠 있었다.
원인을 파 보니 **자료가 없던 게 아니라 구해 놓고 버린 것**이었다 — §4 참조.

## 2. 진단 — ①~⑤ 각 구간의 문제

```
① 사업안을 읽는다 → ② 찾을 숫자 목록을 짠다 → ③ 검색해서 긁어온다
                                                    ↓
                  ⑤ 계산하고 점수 매긴다 ← ④ 이상한 값을 걸러낸다
```

### ① 컨셉의 말을 검색어로 써서 그 말을 확인해 온다
컨셉 `problem` 에 「편의점 저가와 배달 사이」가 있어서 **편의점 도시락가·배달비**를 찾아왔다.
사용자가 쓴 문장을 조사가 되돌려준 것이다.

### ② 물어볼 수 있는 질문이 21개로 고정돼 있다 ★ 뿌리
`ai/app/research/research2/harness/vocab.json` 의 `metric.catalog` 가 전부이고,
여기 없는 것을 쓰면 탈락한다.

| 갈래 | 계량 |
|---|---|
| 구독형 SaaS | 월 구독료 · 고객 획득 비용 · **가입 매장 수** · **누적 가입자 수** · 도입률 · 유료 전환율 |
| 점포 자영업 | 사업체 수 · 종사자 수 · 매장 수 · 종사자 1인 사업체 비율 |
| 공시 | 매출액 · 영업이익 |
| 범용 | 거래액 · 시장 규모 · 시장 점유율 · 연평균 성장률 · **판매가** · 이용 요금 · 문제 경험률 · 인구 · 대상 연령대 인구 비중 |

**냉동식품 제조·판매업을 재는 계량이 「판매가」 하나뿐이고 채널 계량은 아예 없다.**
미용실 예약 SaaS 사례에서 자란 목록이라 업종이 바뀌어도 질문이 안 바뀐다.

곁가지 셋:
- 규칙 7-0(`harness/slot_harness.py:196-203`)이 **가격 슬롯에서 회사 지목을 금지**한다.
  과거 「프레시지 월 구독료 0건」 실측이 규칙으로 굳었고, 프롬프트가 예시로 든
  **배달비·편의점 도시락**이 그대로 나왔다
- 규칙 19(`slot_harness.py:373-385`)가 경쟁사 슬롯에 「매출액+corp_name」을 강제한다.
  주석이 목적을 밝힌다 — *"DART 경로를 한 번 태우기 위한 것이다."* **배관 점검용 값이 산출물로 나갔다**
- **게이트가 「판매 불가」 사유로 집는 칸이 채널인데 채널 계량이 없다.**
  몇 번을 재조사해도 그 칸은 영원히 미확보다

**하네스가 검색에 준 지시는 한 줄짜리 빈칸 채우기다:**
```
[v33-pain·표본N]  {대상} / {계량} / 기간 {기간} / 지역 {지역}  (검색어는 모델이 정함)
```
사업 맥락이 한 글자도 안 들어간다. 12개 슬롯이 이 한 줄씩 받아 질의문 **704개**를 지어냈고,
그중 **172개가 애초에 답이 없는 질문**이었다(「프리미엄 냉동 간편식 누적 가입자 수」 72개,
「신세계푸드 고객획득비용」 48개, 「오뚜기 가입 매장 수」 52개 — 오뚜기는 프랜차이즈가 아니다).
전체 질의는 `queries.txt` 에 있다.

### ③ 찾아 놓고 안 읽었다
```
검색 후보  178
  → 본문 판정   141   (41 잃음: 빈 본문 27 · JS 껍데기 9 · 유료벽 5)
  → 상한 절단   118   (18 잘림 — extract_max_docs=12)
  → 발췌         26
  → 채택         14
```
- **발췌 상한(12건)에 걸려 「모델에게 묻지 않은」 문서 18건** 중에 —
  닐슨 「국내 냉동식품 시장 트렌드」, GMInsights 「냉동식품 시장 규모 및 점유율 통계 보고서」,
  농식품부 계열 「간편식 시장 요약」, 통계청 「2025년 사회조사 결과」
- **문서 앞 20,000자만 본다.** 중간 보기(`extract_window`)는 꺼져 있다. 이번 판에 **257만 자** 버림
- 경로별 수율 — 정부 API(KOSIS·DART) **4/4(100%)** vs 웹 검색 **118→9(17.8%)**
- **정본 보고서를 찾지 않는다.** aT 「가공식품 세분시장 현황 — 냉동식품편」이 무료로 있는데
  한 번도 못 찾았다

### ④ 채택 요건 넷이 전부 「진짜인가」만 묻는다
`rules/fill.v2.json` — 관측 존재 · URL · 조회일 · 인용 대조.
**「쓸모 있는가」는 요건에 없다.** 그래서 배달비 2,400원이 통과한다.

곁가지:
- 인용 검사가 **문장 텍스트만** 본다 → 지방물가정보의 외식비 12,423원이 인용문에 「외식」이란
  낱말이 없어서 탈락(표에서 숫자만 뽑혀서)
- **범위값을 쪼갠다** → "배달비 2,400~3,400원" 한 줄을 두 사실로 나눠 놓고
  다시 **「값이 갈렸다」고 모순 판정**

### ⑤ 엔진이 「추정 불가」라 했는데 화면엔 값이 떴다 ★
원장 최종 보고서(`c3_report.headline_numbers`) 원문:
```
TAM          null  unit_mismatch  추정 불가
SAM          null  unit_mismatch  추정 불가
가격/채널/고객문제/유사제품  null  insufficient  추정 불가
```
**여덟 칸 중 여섯이 「추정 불가」인데 화면에는 11.41조원이 떠 있다.**
같은 원장에서 다른 계산이 돌아 값을 만들어 냈다. **그 경로를 아직 못 찾았다 — 다음 세션의 숙제.**

그 밖에:
- **결함을 잡고도 계산했다** — `unit_mismatch` 를 「찾지 못한 것」에 적어 놓고 그대로 내보냄
- **가정이 값처럼 나간다** — TAM = 거래액 × **0.3**(출처 0건)인데 화면은 값처럼 말함
- **자기 모순** — 같은 성장률이 `15.1464 %/년` 과 `0.1514642 %` 로 공존(같은 근거 인용)
- **성적표가 건수만 센다** — 배달비 5건 → 「가격 확인됨」
- **계산 자리 13칸 중 채워진 2칸은 둘 다 `source: "user_input"`**(예산 30억·가격 8,900원).
  **조사가 알아낸 값은 0개**

## 3. 구조적 결함 다섯 (service-critic 판정, 2026-08-14)

| # | 이름 | 무엇 |
|---|---|---|
| 1 | **화석화** | 과거 판의 실측이 규칙에 굳어 「이번 관측」인 척 찍힌다. `rules/consistency.v1.json:244-250` 의 **카페 POS/SaaS 산문**(코케비즈·토스플레이스·카페24)이 컨셉을 안 보고 **모든 실행에 무조건 복사**된다 — 미용실·반려동물 원장에도 각 9회씩. 같은 성질: 배달비 예시, 「가입 매장 수」, 화이트리스트의 미용실 POS 도메인 40개 |
| 2 | **질문이 답의 이름이 된다** | 인용 게이트가 값의 존재만 재고 개념 일치를 안 잰다. S8 인용 원문은 **"26개 사업장에서 제조 및 판매"**인데 슬롯 라벨 「가입 매장 수」가 값의 이름이 됐다. 41.7%(**아침** 혼밥)를 저녁 타깃 수요로 실은 것도 같은 구멍 |
| 3 | **강등이 흔적 없이 값 자리에 앉는다** | SOM 은 `null` + "안 쟀다"로 정직한데 SAM 은 「수도권 통계 없음 → 전국 값 복사」가 정규 필드로 나가고 그 선언(`proxy_선언`)은 원장 깊이에 남아 봉투까지 안 온다. 계열 C 에 **SAM 계산식이 아예 없어** `verdict.py:338·358` 이 양쪽에 같은 `spec["식"]` 을 쓴다 |
| 4 | **장부가 둘인데 맞춰 보지 않는다** | 성적표는 **조사 활동**을 세고 게이트는 **사업안 연결**을 세는데 둘 다 「확인」이란 낱말을 쓴다. 성장률 100배 공존도 같은 병. 검증이 전부 **「모양」 검증**(필드 존재)이라 **「양」의 검증이 없다** — 분개는 맞는데 시산표를 안 뽑는 장부 |
| 5 | **재개 로직이 「질문의 동일성」을 안 잰다** | `collect = not runpath.complete(source_run)` · `source_run = concept_id`. **완결 판정이 「원장이 있나」만 보고 「그 원장이 지금과 같은 질문에서 나왔나」를 안 본다.** ⇒ 씨앗을 바꿔도 조용히 무시되고, **확장을 구현하고 유료 재실행해도 1분짜리 재채점 no-op** 이 된다 |

**결함 5가 순서를 결정한다** — 이걸 안 고치면 뒤의 모든 유료 검증이 헛돈다.

## 5. 밖의 기준 (web-scout 조사, 2026-08-14)

| | 우리 | 농경연 R742 |
|---|---|---|
| 분량 | 근거 **17건** | **151쪽 · 표 39 + 그림 20** |
| 기간 | 20분 | **10개월** |

**우리에게 없는 산출 항목** — 유통채널별 판매액·비중(대형마트/편의점/체인슈퍼/독립슈퍼) ·

원산지별 원재료 사용비중 · PB 점유율 · 재구매 의도 · 컨조인트 속성 가치.

**무료로 있는 정본** — aT 「가공식품 세분시장 현황 보고서」 **2022 냉동식품편 · 2024 간편식편**.
목차가 곧 우리 필요다:
```
1장 시장 요약 · 2장 조사 개요 · 3장 원료 수급 · 4장 생산·수출입
5장 유통 및 판매 현황  ← 채널 비중

```

## 6. 지난 세션이 잡아 둔 재설계 방향 (참고 — 재설계에 갇히지 말 것)

```
① 사업을 조사 질문으로 번역        (업종 → 조사 표준 항목)
② 항목마다 자료원을 갈라 배정  ★
        ├── 집계 통계(시장 규모·채널 비중·점유율) → 정본 보고서 · 정부 통계
        ├── 제품 사실(가격·용량·구독)           → 웹 · 커머스 상품 페이지
        ├── 최근 일(신제품·가격 인상)            → 웹 · 보도자료
        └── 회사 재무                          → 공시
③ 읽는다 — 보고서는 목차로 들어가 필요한 장을 통째로 (웹은 겨누는 곳만 바꾼다)
④ 거른다 — 진짜인가 + 쓸모 있는가 (판정 한 겹 · 떨어뜨리기 전용 · 라우터와 분리)
⑤ 낸다 — 못 낸 건 안 낸다 (fail-closed · 자기 대사 · 가정 섞이면 범위로만)
```

**②가 사다리가 아니라 분담인 근거** — 웹 수율 17.8% 안에서 성공/실패가 종류로 갈린다.
웹이 성공한 것: 편의점 도시락가(GS25 **상품 페이지**) · 배달비(쿠팡이츠 공지·**보도자료**) ·
풀무원 가입자(**자사 뉴스룸**). 웹이 실패한 것: 시장 점유율(27건 뒤져 0건) · 수도권 시장 규모(18건 0건).
**웹은 「누가 발행한 1차 자료」는 잘 물어오고 「누가 집계한 통계」는 못 물어온다.**

**⑤를 ②③보다 먼저 하는 근거** — ⓐ 재료가 좋아져도 11.41조를 만드는 경로가 남으면 같은 일이 난다
ⓑ **채점자를 먼저 고쳐야 재료 개선이 측정된다** (안 그러면 개선분과 조작분이 한 숫자에 섞인다)

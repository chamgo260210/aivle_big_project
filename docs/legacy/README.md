# docs/legacy — 열지 않는 문서

여기 있는 것은 **현재 상태가 아니다.** 지난 과정의 기록이거나 폐기된 문서다.
`docs/` 를 훑을 때 이 폴더는 건너뛴다 — 213개가 섞여 있어서, 안 걸러 내면 검색 결과의
절반이 지금과 다른 이야기를 한다.

| 폴더 | 무엇 | 왜 남겼나 |
|---|---|---|
| `rebuild/` (185개) | 리빌드 **이력** | 「그때 왜 그렇게 했나」를 되짚을 때만 |
| `archive/` (28개) | 폐기된 문서 | 옛 결정의 근거를 찾을 때만 |

## 지금을 알고 싶으면

| 알고 싶은 것 | 어디 |
|---|---|
| 개수·경로·클래스가 실재하는가 | `python scripts/verify-docs.py` — **문서 말고 이것** |
| 실제 동작 구조 | `docs/architecture/AS_BUILT_ARCHITECTURE.md` |
| 내부 AI 계약 | `docs/contracts/INTERNAL_AI_API_V1_CONTRACT.md` |
| 진행 중인 일 | `docs/*_HANDOFF.md` |

## ⚠ 여기 있는 문장을 인용하지 말 것

현재 코드와 어긋난 문서가 **11건** 확인돼 있다(`ppt/99_MISSING_MATERIALS.md` E절).
그 확인은 `docs/` 본문을 대상으로 한 것이고, **이 폴더는 애초에 낡은 것이 정상**이다.
여기서 읽은 수치·경로·클래스명을 보고서나 발표자료로 옮기면 거의 확실히 틀린다.
